# PA3 answer key

## Review the written work

A good test set includes a receipt that mentions a repair, a mechanical fault that
mentions a price, and a profile question that mentions an appointment. Label by active
request and record which words made the decision. Split by case family if several
tickets are paraphrases. Compare the available versions on development first. Use the
holdout once, and report a comparison on illustrative responses as such.

One judge prompt asks for pass only when a dispatcher can extract exactly one known
queue and it matches the case label. Give it one pass, one wrong queue, and one
malformed output as rubric examples. Record disagreements before changing the rubric.
